# Satanabe UI Studio V1.2

**Não teste pelo pré-visualizador HTML do app Arquivos do iPhone.** Ele pode bloquear JavaScript e mostrar um canvas vazio ou incompleto.

Para editar de verdade, publique no GitHub + Vercel e abra a URL HTTPS diretamente no Safari. Veja `LEIA_ANTES.txt` e `PUBLICAR_NO_IPHONE.md`.

Esta versão exibe uma demonstração estática e um aviso quando o navegador não executa o JavaScript. O editor funcional permanece com as mesmas ferramentas de edição, galeria, temas, exportação SwiftUI e IA opcional.
